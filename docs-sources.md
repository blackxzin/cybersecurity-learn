# Curadoria de estudos

Consulta das páginas oficiais em **1º de outubro de 2026**. A biblioteca usa links
para os materiais dos autores; não redistribui livros ou videoaulas. Os textos e
exercícios das 12 aulas complementares são autorais. Cada aula indica leituras
complementares, e cada material informa idioma e condições de acesso.

| Fonte | Material | Acesso observado |
| --- | --- | --- |
| [CERT.br](https://cartilha.cert.br/livro/) | Cartilha de Segurança para Internet | Livro e PDF gratuitos em português; edição original antiga, acompanhada dos fascículos |
| [CERT.br](https://cartilha.cert.br/fasciculos/) | Fascículos de segurança | Guias gratuitos em português |
| [Harvard](https://cs50.harvard.edu/cybersecurity/) | CS50’s Introduction to Cybersecurity | Videoaulas abertas; conta para envio de atividades; certificado verificado opcional pago |
| [William Shotts](https://linuxcommand.org/tlcl.php) | The Linux Command Line | Edição digital gratuita em inglês; livro impresso pago |
| [OverTheWire](https://overthewire.org/wargames/bandit/) | Bandit | Laboratório gratuito com acesso por SSH |
| [UC Berkeley](https://textbook.cs161.org/) | Computer Security, CS 161 | Livro online gratuito em inglês |
| [CryptoHack](https://cryptohack.org/courses/intro/) | Introduction to CryptoHack | Conteúdo gratuito; conta para registrar soluções |
| [PortSwigger](https://portswigger.net/web-security) | Web Security Academy | Aulas e laboratórios gratuitos; conta para laboratórios/progresso |
| [OWASP](https://owasp.github.io/www-project-web-security-testing-guide/stable/) | Web Security Testing Guide | Guia online gratuito em inglês |
| [NIST](https://csrc.nist.gov/pubs/sp/800/61/r3/final) | SP 800-61 Rev. 3 | Publicação gratuita de abril de 2025; substitui a Rev. 2 |
| [NIST](https://pages.nist.gov/800-63-4/sp800-63b.html) | SP 800-63B-4 | Referência gratuita de autenticação |

O diretório complementar preserva fontes do projeto original e pode incluir planos
pagos. Ele não usa mais selos genéricos de gratuidade nem alegação de que todos os
links foram verificados. A referência ao curso do Google como auditável gratuitamente
foi substituída pelo OpenCourseWare de Harvard, com condições explícitas.
